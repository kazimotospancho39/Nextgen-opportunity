# Opportunity Hub — global product model review

This is an independent global platform prototype. Its visual identity, interface and sample opportunity content are original to Opportunity Hub.

## Please review these journeys

1. Open **Explore all** in the top navigation to see scholarships, fellowships, jobs, internships, grants, camps, training and conferences.
2. Filter by a world region, search for a country or field, and open an opportunity.
3. Create an account, save a listing, submit a sample application and view your progress in My Hub.
4. Open **Gallery** in the navigation or use the homepage **More photos & videos** button. Admins can upload media and choose homepage and Gallery visibility independently.
5. Browse live event countdowns, register before an event starts, and check the dashboard. Open an opportunity detail page to see its deadline countdown; closed applications are disabled.
6. Sign in to the admin studio and publish an opportunity or event, update page-specific copy, and review sample applications and contact messages.
7. Review the checkout page. Local demo mode uses sample USD amounts and never charges real money.

## Questions for the review

- Which countries and regions should be prioritized first?
- Are the global filters, navigation and opportunity categories clear?
- Which additional services, application fields or review stages should be added?
- Is USD the right default display currency, or should people choose a currency?
- Do you prefer Visa/card only, or card plus supported local payment methods?
- What accessibility, language, privacy and safety features should be included?
- Which admin tools are important: editing, approval, scheduling, analytics, exports or notifications?

This is a product model, not a live service. Listings are samples. Demo payments do not process real money. Please use fictional personal details during review.
